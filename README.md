# Plant-Disease-Detection

This project is a deep learning based plant disease detection system built using Python, TensorFlow, and Keras.

## Project Overview
The model is trained on plant leaf images to classify diseases into multiple classes.  
The project includes training code, notebook implementation, output sample, and report.

## Files in this Repository
- `PDD.ipynb` — Google Colab notebook
- `pdd.py` — Python script version of the project
- `PDD_Output.jpg` — sample output/result
- `report.pdf` — project report

## Technologies Used
- Python
- TensorFlow / Keras
- Google Colab
- Deep Learning
- CNN

## Result
The model achieved high validation accuracy for plant disease classification.

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Install the required libraries.
3. Load the dataset.
4. Run all cells to train and evaluate the model.
