# Plant Disease Detection

This project is a deep learning based plant disease detection system built using Python, TensorFlow, and Keras.

## Project Overview
The model is trained on plant leaf images to classify plant diseases into multiple classes.  
The repository contains the notebook, Python script, output image, and report.

## Dataset
Dataset used: [PlantVillage Dataset on Kaggle](https://www.kaggle.com/datasets/emmarex/plantdisease)

## Files in this Repository
- `PDD.ipynb` — Google Colab notebook
- `pdd.py` — Python script
- `PDD_Output.jpg` — sample output/result
- `report.pdf` — project report

## Technologies Used
- Python
- TensorFlow
- Keras
- Google Colab
- CNN

## Result
The model achieved good validation accuracy for plant disease classification.

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Install the required libraries.
3. Download the dataset from the Kaggle link above.
4. Update dataset paths in the code if needed.
5. Run all cells to train and test the model.
